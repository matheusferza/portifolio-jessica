# Portfólio UGC

Portfólio profissional desenvolvido para apresentar uma UGC Creator, com foco em conversão, presença digital e comunicação clara para marcas que buscam conteúdo autêntico.

## Sobre o projeto

Este projeto é uma landing page estática, responsiva e otimizada para destacar os principais formatos de conteúdo UGC produzidos pela criadora. A página apresenta posicionamento profissional, biografia, áreas de atuação, marcas parceiras e canais diretos de contato.

A proposta visual combina uma estética editorial com uma experiência objetiva, pensada para que possíveis clientes entendam rapidamente quem é a criadora, quais tipos de conteúdo ela produz e como iniciar uma conversa comercial.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3
- JavaScript
- Responsive Web Design
- Google Fonts
- Intersection Observer API
- Open Graph Meta Tags
- SEO básico on-page
- Acessibilidade com atributos ARIA
- Git e GitHub
- GitHub Pages ready

## Recursos

- Hero visual com chamada principal e CTA para WhatsApp.
- Seção de formatos estratégicos de conteúdo UGC.
- Área de portfólio organizada por segmentos de atuação.
- Biografia profissional com vídeo integrado.
- Mural de marcas parceiras.
- Rodapé com contato por telefone, WhatsApp e e-mail.
- Layout responsivo para desktop e mobile.
- Animações suaves com suporte a `prefers-reduced-motion`.
- Estrutura preparada para publicação em hospedagem estática.
